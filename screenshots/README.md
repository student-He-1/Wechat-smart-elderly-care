# 截图放置说明

将项目运行截图放入此目录，并在根目录 `README.md` 中引用。

## 建议准备的截图

| 文件名 | 内容 |
| --- | --- |
| `home.png` | 小程序首页 |
| `chat.png` | AI 陪伴聊天界面 |
| `health.png` | 健康管理/数据记录 |
| `medicine.png` | 用药提醒 |
| `fall-detect.png` | 跌倒监测/预警 |
| `voice.png` | 语音交互 |
| `video-cover.png` | 演示视频封面图（建议 16:9） |

## 引用方式

在 README.md 中使用相对路径：

```markdown
![首页](screenshots/home.png)
```

视频链接用封面图跳转：

```markdown
[![演示视频](screenshots/video-cover.png)](https://www.bilibili.com/你的BV号)
```
