# 舒缓音乐文件放置说明

把你喜欢的轻音乐/白噪音/古典乐 mp3 文件放到这个目录，文件名对应：

- 1.mp3 → 清晨·林间鸟鸣
- 2.mp3 → 午后·钢琴慢板
- 3.mp3 → 夜晚·雨声助眠
- 4.mp3 → 山泉·流水潺潺
- 5.mp3 → 古筝·渔舟唱晚
- 6.mp3 → 太极·呼吸导引

## 注意事项

1. 格式必须是 mp3（微信小程序 InnerAudioContext 支持）
2. 建议单首不超过 10MB，避免包体积过大
3. 音乐版权：演示用可选择免费商用音乐（如 pixabay.com/music、freemusicarchive.org）
4. 放好文件后重新编译即可生效
5. 如果想修改歌曲名称/艺术家，编辑 pages/companion/music/music.js 里的 musicList 数组
